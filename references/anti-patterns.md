# 常见问题索引

这些编号是本项目的分类标签，不代表行业共识。保留旧版 A/B/C/D/X 编号便于对照；名称与判据已按场景修订。

先证实问题，再选编号。每条必须有适用情形、位置、影响与修复；严重度按实际影响取 P1/P2/P3。目录缺失、字数或固定句式不足本身均不算命中。不匹配的缺陷可直接描述，无需新增标签。

| 编号 | 问题 | 命中条件与最小修复 |
|---|---|---|
| A1 | 入口过载 | 必需流程被大量无关或条件性细节淹没；按使用时机拆分，不能只凭超过某行数判定 |
| A2 | 缺可执行指导 | 无法从说明决定动作或判断；补具体目标、标准、必要动作 |
| A3 | 资料缺少使用指引 | 只有资料且无法知道如何用于任务；补使用目标和方法；知识指导本身可以是 Skill |
| A4 | 缺异常处理 | 存在实际可能的异常且无处理导致错误；补相应停止、询问或回退，无固定数量 |
| A5 | 选择范围含糊 | 当前描述会混淆相关任务；收窄能力边界，无需统一触发语模板 |
| B1 | 重复确定性操作不可靠 | 已知易错的重复步骤缺可靠执行方式；复用现成工具或脚本，不强制工作流 |
| B2 | 无依据的自动执行承诺 | 定时或无人值守承诺没有宿主支撑；补机制或调整承诺 |
| B3 | 计算或格式操作漂移 | 需要精确处理的数据被要求无校验地临场计算；用工具或验证，Agent 可理解结构化输入 |
| B4 | 易错请求缺校验 | 复杂参数、转义或外部请求没有可靠构造方式；校验或封装关键步骤 |
| B5 | 不可接受的重复副作用 | 重试可能重复发送、写入等且无处理；去重、停止或恢复，仅作用于相关写操作 |
| C1 | 条件性知识挤占入口 | 长资料影响必需指令的可用性；按需引用，短且必要的知识可内嵌 |
| C2 | 模板维护失配 | 重复模板已经不一致或难以同步；集中维护；短模板内嵌可接受 |
| C3 | 要求无法判定 | 必需要求只写“质量要高”等且无判断依据；给可操作标准 |
| C4 | 无依据的事实或结论 | 要求或示范事实判断却无证据；增加来源或保留不确定性 |
| C5 | 关键动作含糊 | 必需步骤只有“处理好”等且无法执行；补动作、分支或产出 |
| D1 | 共享变更不可追踪 | 长期共享确有版本区分需要却无法识别内容；提供版本、提交或其他适当标识 |
| D2 | 必需依赖说明不足 | 必需工具或环境无法从材料识别；补环境、接口、权限要求，凭证写获取方式不写秘密 |
| D3 | 可变依赖无维护依据 | 依赖持续变化的 API/规则却无法追溯或更新；补来源与更新条件 |
| X1 | 审查要求与用途错配 | 把创作任务强制按工具执行、目录或交付等级审查，或把别的平台、旧模型局限当通用约束；按实际用途与环境重新核实 |
| X2 | 必需引用不存在 | 按已确认的解析基准与运行机制，必需资源确实不可取得；补资源或修路由；示例、动态占位、外部资源与基准歧义先核实 |
| X3 | 资源发现路径缺失 | 有实际需要的资源却无法被发现；补直接或间接路由，未直接引用不等于无用 |
| X4 | 需要判断却被机械流程限制 | 输入有变化且死步骤导致错误；补判断依据和分支 |
| X5 | 占位包装 | 文件齐全但核心内容仍是无效占位；补实际能力，不因目录存在放行 |
| X6 | 不相关任务混杂 | 多个独立目标已造成触发或执行冲突；按独立使用需求拆分，无关冲突不成立时不拆 |
| X7 | 隐性个人上下文 | 当前使用者无法理解必要的个人指代；展开必要信息，作者自用已知背景不强制外化 |

不要在报告中逐条复述未命中的标签；只呈现有证据的问题。
